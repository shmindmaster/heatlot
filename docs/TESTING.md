# Testing

```text
docker compose run --build --rm verify
docker compose run --rm gate
docker compose run --rm drill
```

`verify` is `npm run verify:all`: regenerate the dataset and packets, run the unit tests,
schemas, evals, mutations, MCP smoke, the packet verifies, the two cert checks, the tamper
check, and the three demos. Each step has an expected exit code. A refusal exits 3.
`gate` regenerates this file from `evals/gate.json`. `drill` must block every deliberate
regression under `evals/regressions/`.

Browser checks, when the image has Playwright: `docker compose run --rm browser` and
`docker compose run --rm console`. Live provider calls are `npm run verify:live` with
`HEATLOT_LIVE=1` and are not part of CI.

## Release gate benchmark

Generated by `npm run gate`. Deterministic: no timestamps, no model calls. CI regenerates
this file and fails if the committed copy differs.

|---|---|---|---|

| guard-coverage | PASS | 30/30 caught | >= 30 mutations, all caught |

| replay-determinism | PASS | 2 runs, byte-identical ledgers | 2 identical ledgers |
| audit-replay | PASS | audit exit 0, tamper-check exit 0 | both exit 0 |
