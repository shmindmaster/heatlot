# API

The HTTP contract is [`docs/api/openapi.json`](api/openapi.json), generated from the route
declarations by `npm run docs:openapi`. Do not hand-edit it. A release compares that path
with the copy in the latest `v*` tag that contains it.

Everything below is generated by `npm run docs:reference` from the MCP servers and
`schemas/`. Do not hand-edit it.

## coc-report

**Certificate-of-Conformance completeness report.** Fail-closed contract wrapping scripts/verify-completeness.mjs output. Structural rules (allOf if/then): (a) status=complete requires verifier.exit_code 0, forbids missing_records, and requires every item on_file===true; (b) status=incomplete requires verifier.exit_code 3 and at least one missing record; (c) any item claimed on_file:true must carry a non-null 64-hex sha256. A fabricated 'present' claim cannot validate.

# MCP tool reference: heatlot

Generated by `npm run docs:reference` from the live `tools/list` result (`mcp-servers/heatlot/catalog.json`). Do not edit by hand; CI fails if this file drifts from the server.

Protocol revision negotiated: **2026-07-28**. The server also serves the 2025-era handshake (dual era), over stdio by default or over Streamable HTTP on 127.0.0.1 with `--http [port]`.

4 tools over the receiving queue. They call the HTTP API's routes in process, so the MCP and HTTP contracts are one. `packets.inspect` appends signed receipts and is the only tool that writes; there is no release tool, because release is an inspector's decision. Each returns typed `structuredContent` that conforms to its output schema. Inputs are strict: an unknown argument is refused, not dropped.

`tools/list` is cacheable for 60 minutes (`cacheScope: public`): the catalogue is fixed for a release and holds no tenant data.

|---|---|---|---|---|---|
| [`documents.lines`](#documentslines) | Read a document's text layer | true | true | false | false |
| [`packets.inspect`](#packetsinspect) | Inspect a packet and cite why | false | false | false | false |
| [`packets.list`](#packetslist) | List the receiving queue | true | true | false | false |
| [`receipts.verify`](#receiptsverify) | Verify a packet's receipts | true | true | false | false |
