# MCP tool reference: kestrel-foundry-data

Generated by `npm run docs:reference` from the live `tools/list` result (`mcp-servers/kestrel-foundry-data/catalog.json`). Do not edit by hand; CI fails if this file drifts from the server.

Protocol revision negotiated: **2026-07-28**. The server also serves the 2025-era handshake (dual era), over stdio by default or over Streamable HTTP on 127.0.0.1 with `--http [port]`.

All 10 tools are read-only lookups over the synthetic Kestrel Castings dataset (the original foundry example). Each returns typed `structuredContent` that conforms to its output schema. Inputs are strict: an unknown argument is refused, not dropped.

`tools/list` is cacheable for 60 minutes (`cacheScope: public`): the catalogue is fixed for a release and holds no tenant data.
