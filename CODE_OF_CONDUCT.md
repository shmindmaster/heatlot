# Code of conduct

## Our standard

We want participation in Heatlot to be useful, respectful, and safe. Examples of
welcome behavior include giving specific technical feedback, testing claims,
crediting others, accepting correction, and making room for people with
different experience levels and backgrounds.

Harassment, threats, personal attacks, discriminatory language, sexualized
content, deliberate disruption, publishing private information, and sustained
bad-faith behavior are not acceptable in project spaces.

## Enforcement

Report conduct concerns privately to `sarosh.hussain@gmail.com`. Reports will be
reviewed in context and handled as confidentially as practical. The maintainer
may edit or remove content, limit participation, or ban contributors when
necessary to protect the project and its participants.

This code applies in repository discussions and in public spaces where someone
is representing Heatlot.

## Attribution

This policy is informed by the Contributor Covenant 2.1 and the Rust project
Code of Conduct, adapted for a small maintainer-led project.
